## 自动审查执行

先用指定 Skill 的 helper 对开放 PR 执行 `status --pr <编号>` 并保存完整 JSON，再用已取得对应 Git 对象的隔离仓库执行 `node review-history.mjs run <最新状态JSON> <Git目录>`。它从同一发布版的交付插件复用审查器，只传 Git 文字快照。同类问题按同一编号合并并保留所有位置。成功时自动写审查记录；同一提交直接复用，有线性新增提交则只审增量和旧问题。第三轮起若仍有问题，按回执考虑换做法，继续按新增提交复查。

输出 `ok:false` 时停止本轮审查后续动作，直接用 `reply` 作为最后一条消息首行。超过 30 分钟、审查器退出异常或结果不合格时会带具体原因；失败不会记为审查通过。后续合并前核验和上线回读继续走本手册的 `premerge`、`live`。
